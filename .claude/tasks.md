# Task — DotDE v1.0.0 (rev. 3, dopo la seconda `/04-analyze`)

> Ogni task lascia il codice funzionante e ha un test o una verifica esplicita. I test girano con `pytest` su una home finta, mai sulla home reale. Tra parentesi quadre i finding di `analysis.md` coperti.

## Fase 1 — Fondamenta

- [x] **Task 1: Scaffold del progetto** — `pyproject.toml` (Python ≥ 3.11, `questionary`, `rich`, entry point `dotde`, versione dal file `version`), pacchetto `src/dotde/` con `__init__.py` e `__main__.py`, `main.py` come launcher, cartella `tests/` con config pytest. — DoD: `pip install -e .` riesce; `dotde` e `python -m dotde` stampano `1.0.0`; `pytest` gira senza errori.
- [x] **Task 2: Traduzioni** — `i18n.py` con `t(key, **kw)`, `locales/en.json` e `locales/it.json`, lingua da `LC_ALL`/`LANG`. — DoD: test: `LANG=it_IT.UTF-8` → italiano; `LANG=de_DE` o assente → inglese; chiave mancante in `it` → fallback inglese.
- [x] **Task 3: Rilevamento ambiente** — `detect.py`: `/etc/os-release` (`ID`, `ID_LIKE`, `PRETTY_NAME`), famiglia distro (arch/debian/fedora/suse/sconosciuta), DE da `XDG_CURRENT_DESKTOP` con fallback `DESKTOP_SESSION`, tipo di sessione. — DoD: test con os-release di esempio (CachyOS, Ubuntu, Fedora, openSUSE) → famiglia corretta; test con `KDE`, `GNOME`, `ubuntu:GNOME`, `XFCE`, `Hyprland`, `sway` → DE corretto; variabili assenti → "sconosciuto" senza eccezioni.
